# aic v0.5 小红书发布文案

---

我开源的 aic 更新到 v0.5 了 🎉

这次主要更新：

🔑 **支持调用 Claude Code agent 了**
不用再单独配 API Key，直接复用你本地已登录的 Claude Code / Codex / pi / opencode 的认证，aic 在后台 headless 调用

🎨 **输出格式更美观**
全新的 WCAG 安全配色，明暗终端都清晰；每条提交下方新增文件级统计（+2 −2）

🔄 还加了 `aic use` 一键切换 provider、musl + ARM Linux 支持

---

**aic 是什么？**
一个 AI 驱动的 git commit 工具，能读懂你的代码改动，把一个文件里混合的多种改动自动拆成多个原子提交。Conventional Commits 规范，历史干干净净 🧹

开源免费 MIT，欢迎 Star ⭐
